3. STRUKTUR BERKAS DAN DOKUMEN YANG DIBUTUHKAN
--------------------------------------------------------------------------------
Untuk menjalankan program ini, pastikan berkas-berkas berikut berada dalam satu
direktori kerja:
1. asag_search_engine.py : Kode program utama Python (.py) yang mencakup:
                           - Pembacaan korpus dokumen dari subfolder anggota
                             (Indira/, Sam/, NicSap/, dan corpus/) menggunakan
                             os.walk()
                           - Praproses teks (Case Folding, Normalisasi RegEx &
                             Punctuation, Tokenisasi NLTK, Stopword Removal, dan
                             Stemming dengan PorterStemmer / Sastrawi)
                           - Perhitungan Term Frequency (TF) tiap token per
                             dokumen (nltk.FreqDist) & Document Frequency (DF)
                           - Pembobotan TF-IDF (sklearn TfidfVectorizer) dan
                             penyimpanan ke dalam struktur data Index
                           - Transformasi Transpose matriks index (.transpose())
                             sehingga baris = term/token dan kolom = kode dokumen
                           - Pemrosesan kueri frasa pengguna, pembobotan TF-IDF
                             kueri, perhitungan Cosine Similarity, dan pengurutan
                             dokumen dari kemiripan tertinggi
                           - Mode CLI (Terminal) & Mode Antarmuka Web Pencari
                             Sederhana (Streamlit) untuk BONUS 2.5%
2. README.txt            : Berkas dokumentasi ini (identitas, sumber URL korpus,
                           dan petunjuk kompilasi/eksekusi).
3. Folder PDF/           : Berisi subfolder PDF artikel per anggota kelompok:
                           - PDF/Indira/ (5 artikel PDF)
                           - PDF/Sam/    (5 artikel PDF)
                           - PDF/NicSap/ (5 artikel PDF)
4. Folder corpus/        : Folder hasil ekstraksi teks (.txt) otomatis oleh
                           program dari seluruh berkas PDF di atas.
