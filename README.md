## 4. Cara Menjalankan Program

### Instalasi Dependencies
```bash
pip install nltk scikit-learn pandas numpy pymupdf streamlit PySastrawi
```

### Eksekusi Mode Web UI (Streamlit - BONUS 2.5%)
```bash
streamlit run asag_search_engine.py
```
atau:
```bash
python asag_search_engine.py --ui
```

### Eksekusi Mode Terminal / CLI
```bash
python asag_search_engine.py
```
